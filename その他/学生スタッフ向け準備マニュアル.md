# 学生スタッフ向け Webプログラミング体験授業 準備マニュアル

> ⚠️ 注意：batファイルを実行すると、他のVSCodeやブラウザが終了します。実行前に必ず確認してください。

以下の手順で準備をしてください。

## 1. 教室・掲示物の準備

1. 1階のカウンターから、Webプログラミング体験のポスターと、壁に貼り付けるためのセロハンテープを受け取る
2. 2階の教員室から7A教室の鍵を借りる
   - 教員室に入るときは3回ノックしてそのまま入り、「SAの◯◯です。7A教室の鍵を取りにきました」と伝える
   - 鍵の場所や、借りるときの記入場所は先輩か先生に確認して覚える（文章で説明するのが難しいため、ここでは省略）
3. 7A教室に行き、ポスターをゴミ箱の上の延長線くらいの位置に貼り付ける

## 2. PCの準備

1. PCが置いてある棚の鍵は、ギザギザを下向きに差し込んで左に回すと開く
2. PCは「参加者人数＋2台」程度を用意する（参加者の増加や、使用中PCの不具合に備えるため）
3. ログインアカウント情報
   - アカウント：`design`
   - パスワード：`Ds@20150312`

## 3. Webプロセットアップ.bat をデスクトップに置く

デスクトップに `Webプロセットアップ.bat` が**なければ**、学校のサーバーである `¥¥file` フォルダからコピーしてデスクトップに配置してください。

（すでにデスクトップにある場合は、この手順は不要です。）

## 4. パワポをデスクトップに移動する

教員機のデスクトップに `Webプログラミング体験_資料.pptx` が**なければ**、以下を行ってください。

1. 学校のサーバーである `¥¥file` フォルダにある `Webプログラミング体験_資料.pptx` をデスクトップにコピーする
   - もし見つからなければ、デスクトップの `Webプロセットアップ.bat` を実行し、開いたエディタ（VSCode）の中にある `Webプログラミング体験_資料.pptx` をデスクトップに移動する

（すでにデスクトップにパワポがある場合は、この手順は不要です。）

## 5. パワポに今日の担当者名を入力する

教員機のデスクトップの `Webプログラミング体験_資料.pptx` を開き、**1枚目のスライド**にある「本日サポートする学生スタッフ」の「名前」の欄に、今日の担当者の名前を入力してください。

## 6. 直前の環境準備

1. デスクトップの `Webプロセットアップ.bat` を実行する
2. ブラウザ（Google Chrome）が自動で開いたら、環境は整った状態です
   - このときブラウザは自動的にゲストモードで開きます（前の参加者の入力履歴などを引き継がないようにするため）。特別な操作は不要です。
3. `Alt + Tab` を押して、エディタ（VSCode）の画面が出てくれば準備完了です

以上で、参加者を迎える準備は完了です。

## 7. 体験授業終了後の片付け

1. `Alt + F4` を押しまくって、開いているウィンドウを順番に閉じていく
2. 「シャットダウンしますか」のダイアログが出たら、そのままシャットダウンする
   - `Alt + F4` が効かないときは、キーボードの「Fnキーロック」がかかっていて、F4キーが本来のファンクションキーとして動作していない可能性があります（ノートPCに多い）。以下を試してください。
     - `Fn + Esc` を押す、またはキーボードの鍵マークが付いたキー（`Fn + F4` など機種による）を押して、Fnロックを解除してからもう一度 `Alt + F4` を押す
     - それでも効かない場合は、何かのウィンドウやダイアログがフォーカスを奪っている可能性があるため、`Alt + Tab` でウィンドウを切り替えて確認し、`Esc` を押してから改めて `Alt + F4` を押す
     - それでもだめな場合は、タスクバーの「スタート」ボタン →「電源」→「シャットダウン」から終了する

## トラブルシューティング・補足

- **動作確認をしたい場合**：毎回、既存データを削除してから `git clone` し直しているため大丈夫なはずですが、不安であればパワポの内容と照らし合わせて、コードや見た目が修正前の状態になっているか確認してください。
- **`Webプロクリーン.bat` / `Webプロサーバー起動.bat` の場所**：デスクトップには配置されません。学校のサーバー（`¥¥file`）か、`Webプロセットアップ.bat` を実行したときに開くプロジェクトフォルダ（`C:\Users\（サインインしているアカウント名）\AppData\Local\web_taiken\project`）の中にあります。エクスプローラーのアドレス欄に `%LOCALAPPDATA%\web_taiken\project` と入力しても開けます。
- **データを全て削除したい場合**：`git clone` 先（上記のプロジェクトフォルダ）はわかりにくい場所に保存されているため、`Webプロクリーン.bat` を実行してください。プロジェクト一式に加え、VSCodeやブラウザも終了します。
- **ブラウザで体験用サイトが開けなくなった場合**（PHPサーバーが閉じてしまった場合）：`Webプロサーバー起動.bat` を実行してください。
- **エラーが起きて原因を調べたい場合**：`Webプロセットアップ.bat` の実行内容はすべてログファイル（`C:\Users\（サインインしているアカウント名）\AppData\Local\web_taiken\web_taiken_setup_log.txt`、アドレス欄には `%LOCALAPPDATA%\web_taiken\web_taiken_setup_log.txt`）に記録されています。
